# 多平台发布工作流程

## 原稿、平台与语言版本

保存完整原稿、素材和写作画像，再选择目标平台与输出语言。同一原稿可以保留同一平台的多个语言版本；每个版本分别编辑和审阅，重新生成只替换所选平台的指定语言。

规则模式整理已有文字，不执行翻译。新增语言可以调用配置的 AI 服务，或复制一个待编辑版本。复制不会自动翻译，也不会继承确认状态。

## 配图与审阅

各版本分别选择素材并调整顺序。文章支持正文插图和 HTML 预览；素材选择用于后续导出、任务快照及结果记录。标题、正文、标签、输出语言、配图或顺序发生变化后，需要重新确认。

审阅时检查平台字数、话题标签、素材数量与缺失图片引用。小红书字数校验包含话题标签；X 使用保守加权估计，实际发布仍由平台编辑器或接口校验。

## 发送前核对

为具体语言版本选择账号和连接方式，再查看核对页：

- 本次发送的标题、语言、账号名称与图片顺序。
- 实际路径：提交发布、写入草稿、浏览器交接或自建服务。
- 连接检查的时间与范围：参数检查与凭据检查分别展示。
- 同账号待处理任务，以及相同文案与素材的既有记录。

连接检查失败、素材不兼容或待处理任务冲突会阻止创建任务。已有相同内容记录时，需要核对并明确确认再次发送。同一账号可以接收不同语言的独立内容。

## 发布任务与实际结果

即时或预约任务保存独立的文案、语言及素材快照，后续修改原稿不会改变历史任务内容。草稿、平台审核中、已公开发布、结果未知、失败与未发送的阻塞分别管理。结果未知时不会自动重发。

在浏览器或平台后台完成的操作，可以通过“记录浏览器发布结果”写入工作台，无需配置发布连接。记录操作只保存数据，不发送内容；浏览器记录也不能通过队列自动重发。

记录已发布需要帖子链接或成功截图。阻塞或失败需要填写原因与下一步。后续核实保存结果变更历史，凭证与对外宣传附件分别管理。同版本、同账号的重复记录提示更新原记录；相同幂等请求返回既有结果。

## 带图导出

文章 HTML 导出将所选本地图片嵌入文件，保留正文内图片位置，未引用的图片附件追加一次。导出文件可以独立打开，不依赖本地上传服务。

同一平台存在多个语言版本时，导出需指定具体版本。导出稿不会自动设置平台封面、上传后台图片或执行最终群发，这些步骤取决于实际连接与平台编辑器。

## 运行数据与 Git

账号凭据、模型密钥、数据库、发布内容、远端链接和截图凭证属于本地运行数据，不随源码提交。默认 data/、work/、环境文件、数据库文件、密钥、浏览器登录状态及本地截图输出目录由 Git 忽略；.env.example 仅提供无密钥的配置示例。

如果使用自定义数据目录，仍需确保它位于仓库外，或另行添加忽略规则。备份数据库时保留本机加密密钥与上传目录；备份不得进入公开源码仓库。

## 验证范围

自动测试使用临时数据库、模拟 HTTP 服务和虚构账号，覆盖多语言共存与独立确认、图片顺序、冻结快照、重复发送检查、幂等记录、审核状态更新和带图导出。类型检查与生产构建验证客户端及服务端集成。

这些检查验证功能与协议行为，不证明真实账号已取得发布权限。真实操作记录与凭证保留在本地，不作为公开测试数据。
