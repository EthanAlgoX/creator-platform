# 创作者工作台

把一份原稿整理为经过审阅的多平台内容，再通过已配置连接发布、保存草稿或交给浏览器完成操作。

[English](./README.md) · **简体中文**

![创作者工作台：原稿编辑器、写作画像、平台选择，以及写原稿、适配与审阅、分发三个阶段](./docs/images/creator-platform-workbench.jpg)

一个支持本地运行与受认证服务器部署的个人工作台。界面默认使用 English，可切换 **English / 简体中文**，选择保存在浏览器中。界面语言与写作画像中的内容输出语言相互独立。

## 从原稿到分发

| 阶段 | 可以做什么 |
| --- | --- |
| **1. 写原稿** | 输入主题、正文和写作画像，添加图片、视频或 PDF 附件。 |
| **2. 适配与审阅** | 生成规则稿或 AI 稿，逐平台编辑，检查长度与素材要求，预览并确认。 |
| **3. 分发** | 复制或导出，选择兼容账号，创建即时或预约任务，跟踪各目标的实际结果。 |

## 核心功能

- **一份原稿，独立平台版本。** 保存内容库和可复用画像，生成缺失版本时保留已有编辑；重新生成必须明确确认替换。
- **规则整理或自选 AI 服务。** 规则适配无需模型；AI 使用配置的 Chat Completions 兼容服务，每批最多处理六个平台。
- **发送前逐平台审阅。** 编辑标题、正文、标签和 X 串帖，预览文章 HTML，检查平台约束；原稿或画像变化后需要重新审阅。
- **可搜索的平台目录。** 按地区、格式和实际发布路径筛选 102 个内容适配目标，查看接入条件与上游实验性标记。
- **可核对的分发记录。** 每个账号保留入队时的内容快照、排期和结果，区分草稿、浏览器交接、结果未知和已发布。未知发布请求不会自动重发。
- **可导出的内容与加密凭据。** 导出 Markdown、文章 HTML 或 JSON；账号密钥和模型 Key 加密保存在 SQLite 中，浏览器草稿备份与服务端保存分别提示。

## 开始使用

需要 **Node.js 22.13+** 和 npm。SQLite 使用 Node 内置模块；工作台本身无需独立数据库服务器或 Redis。

```bash
git clone https://github.com/EthanAlgoX/creator-platform.git
cd creator-platform
npm ci
npm run dev
```

打开 [http://127.0.0.1:4317](http://127.0.0.1:4317)。开发 API 使用端口 `4318`，Vite 代理 `/api` 与 `/uploads`。

构建后用单个本地生产服务运行：

```bash
npm run build
npm run start:production
```

打开 [http://127.0.0.1:4318](http://127.0.0.1:4318)。此命令运行编译后的 JavaScript，启动前须先构建。可选环境变量见 [`.env.example`](./.env.example)；本地进程不会自动读取 `.env` 文件。

Docker / Nginx 认证部署及 `/creator-platform/` 子路径配置见 [部署说明](./deploy/README.md)。远程模式必须明确开启；默认本地服务只接受回环访问。应用仍是单用户工作台。

## 平台覆盖与连接方式

目录包含 **102 个内容适配目标：国内 61 个、海外 41 个**。这是创作与格式适配目录，不表示所有目标都能无人值守发布。各连接方式覆盖的集合有重叠，数量不能相加。

| 连接方式 | 当前范围 | 使用条件 |
| --- | --- | --- |
| 原生 API / Webhook | 18 个连接器，发布或草稿能力依连接器而定 | 自有凭据、资源 ID、平台权限与额度。企业机器人检查仅核对配置；Teams 受理后仍需确认投递。 |
| Postiz | 32 个 provider 映射，提交发布任务或保存 Postiz 草稿 | 可访问实例、已授权账号及平台专属设置；本地文件通过 Postiz 媒体接口上传。 |
| MultiPost | 69 个公开注册键，前台浏览器交接 | 安装扩展、信任工作台 hostname 并登录目标网站；用户继续完成操作，部分上游适配为实验性。 |
| Wechatsync | 17 个草稿映射 | 可访问 HTTP 桥、浏览器扩展和登录会话；最终公开发表在目标网站完成。 |
| 小红书 MCP REST | 图文或同机单 MP4 | 单独运行且已登录的服务；视频需要读取同机文件，未实现远程或容器路径映射。 |
| 自定义 Webhook | 自供接收器可对接任意目录目标 | 用户提供发布服务与授权；只有明确远端结果才计为已发布或草稿。 |

Quora、Qiita、Zenn、note 当前没有专用发布集成，可复制、导出或自供 Webhook。视频目标适配文案，视频文件需自行准备。预约任务仅在服务运行时执行，浏览器交接仍需前台操作。

认证服务器上的上传文件保持私有。依赖第三方读取这些 URL 的路径受限制，请选择直接上传文件字节的连接器。素材、草稿与权限边界见 [完整平台映射](./docs/PLATFORM-COVERAGE.md) 与 [用户指南](./docs/USER-GUIDE.md)。

## 验证

```bash
npm run typecheck
npm test
npm run build
```

自动检查使用临时 SQLite、模拟 HTTP 服务与假浏览器消息，验证工作流和协议行为，不证明真实账号拥有发布权限。开发验证没有向真实社交平台发帖。

## 数据与备份

数据默认位于 `data/`，可通过 `CREATOR_DATA_DIR` 修改。文件复制备份前停止服务，再复制**整个目录**，包括 `creator.sqlite`、`vault.key` 和 `uploads/`。数据库与密钥须成对保留才能恢复已保存凭据。账号和模型密钥加密保存；普通原稿、画像和任务记录并非整库加密。不要把私有数据或凭据提交到 Git。详见 [备份与恢复](./docs/USER-GUIDE.md#backup-and-restore)。
